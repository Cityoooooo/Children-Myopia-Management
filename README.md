# 儿童近视管理方案匹配 Demo

面向家长科普的**手机端 Demo**：输入儿童年龄、当前近视度数和眼轴增长趋势后，横向浏览 5 个近视管理方案的匹配程度（五星），并查看主要依据、实施要求与复查管理。

本 Demo 仅用于近视防控科普及方案理解，不构成诊断、治疗建议或临床决策。

## 本地预览

在项目根目录启动静态服务：

```bash
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。建议用手机或开发者工具的手机预览查看。

也可直接打开 `index.html`。

## 使用方式

1. 用滑动条选择年龄（6～16 岁）和当前近视度数（50～800 度，步进 25 度）
2. 选择眼轴增长趋势：低 / 中 / 高
3. 左右滑动（或点箭头、拖动）查看 5 个方案卡片
4. 卡片只展示五星匹配程度，不展示分数

方案卡片按匹配星级从高到低排列；星级相同时顺序为：OK镜、低浓度阿托品、离焦框架眼镜、OK镜 + 低浓度阿托品、离焦框架眼镜 + 低浓度阿托品。

## 调整规则

评分、文案、输入范围都集中在 [`js/config.js`](js/config.js)，医学专家调整规则时原则上只改该文件。

可配置项包括：

- 年龄 / 近视度数范围与步进
- 年龄、度数、眼轴增长趋势评分
- 方案基础匹配分、联合方案加成
- 五星映射阈值
- 方案名称、主要依据模板、实施要求、复查管理
